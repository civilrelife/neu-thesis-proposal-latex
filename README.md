# 东北大学 · 硕士学位论文或实践成果开题报告 · LaTeX 模板

> 依据**东北大学机械工程与自动化学院官方 Word 模板（附件6）**逐项实测还原的 LaTeX 空白模板。
> 排版参数（页边距、字体、字号、加粗、封面坐标）均从官方模板的 PDF/Word 属性中**实测提取**，不是目测仿制。

## 特性

| 特性 | 说明 |
|---|---|
| **封面逐点对齐** | 学号/标题/6 个字段的位置与官方模板误差 < 1pt（实测：题目 +0.2pt、导师 0.0pt） |
| **字体严格照模板** | 学号 黑体四号、标题 黑体二号、字段 宋体三号**加粗**、填表说明 宋体 23.5pt、表头 黑体五号 |
| **"整页背景框"** | 五个栏目的框线不是表格线，而是按页绘制的背景框 → **每页都框满整页**，不会出现"表格跨页断开/铺不满" |
| **中文标点不出框** | 框已按标点悬挂留出余量，正文不会跑到框外 |
| **字体自动回退** | 本机（Windows）用宋体/黑体；**Overleaf / Linux 自动改用 TeX Live 自带 Fandol**，无需改代码 |
| **一处不留空** | 零 Overfull 警告、零文字出框（已在 26 页正文上逐页实测） |

## 快速开始

### 方式一：本机命令行
```bash
xelatex 开题报告模板.tex     # 需要跑两遍（背景框要用到页码引用）
```
或直接双击 **`重新编译.bat`**。

### 方式二：网页端编辑（推荐给不熟悉命令行的人）
```bash
python latex_web_editor.py
```
然后浏览器打开 <http://127.0.0.1:8766/> —— 左侧改文字，点「保存并编译」，右侧实时看 PDF。

### 方式三：Overleaf（在线协作）
1. 把整个文件夹压成 zip
2. Overleaf → **New Project → Upload Project** → 选这个 zip
3. **Menu → Compiler → XeLaTeX**（⚠️ 必须是 XeLaTeX，不能用 pdfLaTeX）
4. Recompile

## 怎么填

全局搜索 `@@`，把所有占位符替换成你的内容：

| 占位符 | 位置 | 说明 |
|---|---|---|
| `@@学号@@` | 封面右上 | 纯数字 |
| `@@论文题目@@` | 封面 | 建议 ≤ 25 字 |
| `@@姓名@@` / `@@学科专业@@` / `@@学院（部）@@` / `@@导师@@` / `@@副导师@@` | 封面 | 副导师没有就填"无" |
| `@@一、立论依据正文@@` | 第一栏 | 见文件内写作提示 |
| `@@二、文献综述正文@@` | 第二栏 | 建议分五节，每节末给评述 |
| `@@三、研究内容（1）…@@` / `（2）…` | 第三栏 | 第（2）项里放论文三级目录 |
| `@@四、研究基础（1）…@@` / `（2）…` | 第四栏 | 经费预算表按需增删行 |
| `@@阶段及内容@@` 等 | 第五栏 | 工作计划表 |

> 提示：每个栏目里都留了 `%%` 注释形式的**写作提示**，交稿前删掉即可（注释本来就不会被打出来）。

## 排版规格（实测自官方模板，改前请三思）

| 元素 | 字体 | 字号 | 加粗 |
|---|---|---|---|
| 页边距 | — | 上 2.50cm / 下 2.10cm / 左右 2.00cm（＝70.9 / 59.5 / 56.7 pt） | — |
| 校徽宽度 | — | 6.84 cm（＝193.9 pt） | — |
| 学号 | 黑体 SimHei | 四号 14pt | 否 |
| 论文标题 | 黑体 | 二号 22pt | 否 |
| 封面字段 | 宋体 SimSun | 三号 16pt | **是**（Word 属性 `bold=-1`） |
| 填表说明标题 | 宋体 | 23.5pt | 否 |
| 填表说明正文 | 宋体 | 14.5pt | 否 |
| 栏标题 / 提示行 | 黑体 | 小四 12pt | 否（黑体本身即粗体效果） |
| 正文 | 宋体 | 小四 12pt | 否 |
| 工作计划表头 | 黑体 | 五号 10.6pt | 否 |

**五个栏目的框**：顶边从文字区顶部下移约 19pt（让栏标题留在框外），续页则框满整页；左右各比文字区宽 9pt（容纳中文标点悬挂）。

## 常见问题

**Q：编译报 `fontspec Error: The font "SimSun" cannot be found`？**
A：说明不在 Windows 上（如 Overleaf），模板会自动回退到 Fandol；若仍报错，请确认编译器选的是 **XeLaTeX**。

**Q：为什么不用 tabular/tabularx 直接画那五个框？**
A：因为表格的**行不能跨页**：内容一长，整个表格会在分页处断开、留白，甚至被 Word/LaTeX 静默截断。本模板改用 `eso-pic` 的**整页背景框**画边框、正文用普通段落自然流动，于是每页都框满、内容不会丢。

**Q：想把某一栏拆到新页？**
A：在需要的地方加 `\newpage` 即可（模板本身每栏已自动另起一页）。

**Q：修改行距/首行缩进？**
A：在导言区找 `\linespread{1.25}`（行距）与 `\setlength{\parindent}{2em}`（首行缩进）。
